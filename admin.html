🛠️ Google Sheets 연동 설정 가이드
아래 순서대로 따라하시면 약 10분 안에 설정 완료됩니다.
1
Google Sheets 새 파일 만들기
sheets.new에 접속하여 새 스프레드시트를 만드세요.
파일명을 "수출상담회 일지_2025 BIO USA" 등으로 저장합니다.
2
Apps Script 열기
상단 메뉴에서 확장 프로그램 → Apps Script를 클릭합니다.
3
아래 코드 전체 복사해서 붙여넣기
기존 코드를 모두 지우고 아래 코드를 붙여넣으세요.
// appsscript.gs 파일에서 복사하세요 // (같은 폴더의 appsscript.js 파일 참고)
4
웹 앱으로 배포
오른쪽 위 배포 → 새 배포 클릭
유형: 웹 앱 선택
실행 대상: 나
액세스 권한: 모든 사용자
→ 배포 클릭 후 URL 복사
5
URL을 왼쪽 사이드바에 붙여넣기
복사한 웹 앱 URL을 왼쪽 "Apps Script URL" 항목에 붙여넣고 저장하세요.
이후 index.html 의 CONFIG.scriptUrl 에도 동일하게 입력하시면 됩니다.
6
index.html을 GitHub Pages로 배포
github.com에서 새 Repository 생성
index.html 파일 업로드 → Settings → Pages → Branch: main 선택
생성된 URL (예: yourname.github.io/expo-form)을 카카오로 공유!
